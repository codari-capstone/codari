# Codingmon

채점 근거를 활용한 AI 오답 분석 기반 코딩테스트 학습 플랫폼

틀린 이유를 근거를 가지고, 정답 코드를 주지 않고 설명한다. 채점은 백준처럼 판정만 공개하고, 학습자가 원할 때 AI가 채점 결과를 근거로 원인을 설명하고 힌트를 관찰 → 방향 → 원리의 3단계로 하나씩 연다.

> 졸업작품으로 개발 중이다 (2026.09.28 ~ 12.06).

## 구조

| 폴더 | 내용 |
|---|---|
| `web/` | 프론트엔드 · React 19, Vite, TypeScript |
| `api/` | 백엔드 · Spring Boot 4, Java 21, PostgreSQL 16 |
| `judge/` | 채점 서버 · Judge0 자체 호스팅 설정 |
| `infra/` | Docker Compose, AWS 배포 |
| `contracts/` | OpenAPI 명세 · 프론트엔드와 백엔드의 계약 |
| `docs/` | 설계 문서 · 기능명세서, 기술 스택, 협업 규칙, AI 기능 정의 |

문제 지문, 정답 코드, 비공개 테스트는 비공개 저장소 `problems`에 따로 둔다.

## 일정

| 마일스톤 | 기한 |
|---|---|
| ① 제출 → 판정 · 쉬운 설명 | 4주차 (10/25) |
| ② AI 분석 → 단계별 힌트 → 재제출 | 6주차 (11/8) |
| ③ 학습 리포트 · 추천 포함 MVP 고정 | 7주차 (11/15) |
| ④ AWS 배포 · 사용자 검증 | 9주차 (11/29) |
| ⑤ 최종 발표 | 10주차 (12/6) |
